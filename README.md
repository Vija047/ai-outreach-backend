# AI Outreach API — Render deployment

## Deploy (Docker on Render)

1. Push this repo and create a **Blueprint** from `render.yaml`, or create a Web Service:
   - **Root Directory:** leave empty (uses repo root)
   - **Dockerfile Path:** `./backend/Dockerfile`
   - **Docker Context:** `./backend`
   - **Health Check Path:** `/api/v1/health`

2. Set these environment variables in the Render dashboard (`sync: false` ones):

| Variable | Example / notes |
|----------|-----------------|
| `DATABASE_URL` | Neon Postgres URL (`?sslmode=require`) |
| `REDIS_URL` | Upstash `rediss://default:…@….upstash.io:6379` |
| `FRONTEND_URL` | `https://your-app.vercel.app` |
| `CORS_ORIGINS` | Extra origins, comma-separated (optional) |
| `GOOGLE_CLIENT_ID` / `SECRET` | Google Cloud OAuth |
| `GOOGLE_CALLBACK_URL` | `https://YOUR-API.onrender.com/api/v1/auth/google/callback` |
| `EMAIL_USER` / `EMAIL_PASS` | Gmail + Google App Password (required for OTP) |
| `EMAIL_FROM` | e.g. `AI Outreach <you@gmail.com>` |
| `SMTP_HOST` / `SMTP_PORT` | Defaults: `smtp.gmail.com` / `587` |
| `OPENAI_API_KEY` | OpenRouter `sk-or-v1-…` |
| `OPENAI_HTTP_REFERER` | Same as `FRONTEND_URL` |
| `FIRECRAWL_API_KEY` | Scraping |
| `TAVILY_API_KEY` | News enrich (optional) |
| `ROCKETREACH_API_KEY` / `HUNTER_API_KEY` | Contacts (optional) |

`JWT_SECRET` is auto-generated by the blueprint. `PORT` is injected by Render.

3. Google Cloud Console → OAuth client → add authorized redirect URI matching `GOOGLE_CALLBACK_URL`.

4. Frontend: set `NEXT_PUBLIC_API_URL=https://YOUR-API.onrender.com/api/v1`.

## Local

```bash
docker compose up -d          # postgres + redis
cp .env.example .env          # fill secrets
npm ci
npx prisma migrate deploy
npm run start:dev
```

- API: `http://localhost:3001/api/v1`
- Health: `GET /api/v1/health`
- Swagger (non-production only): `http://localhost:3001/api/docs`

## Production notes

- Migrations run automatically on container start (`prisma migrate deploy`).
- Swagger is disabled when `NODE_ENV=production`.
- CORS allows only `FRONTEND_URL` + `CORS_ORIGINS` in production (no localhost).
- Free Render plan sleeps; use a paid plan + always-on Redis for reliable BullMQ jobs.
